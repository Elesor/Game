# Legacy of RSUE

«Legacy of RSUE» представляет собой 2D adventure puzzle – пиксельная графика, вид сверху, решение головоломок и задач для исследования нашего университета и продвижения по сюжету.

## Особенности

- Плавное 2D движение с использованием физики Rigidbody2D
- Система паузы с остановкой игровой физики
- Определение состояния бега для анимаций и других механик
- Преобразование координат игрока в экранные для UI элементов
- Синглтон паттерн для глобального доступа к игроку

## Системные требования

- Операционная система: Windows 10/11
- Процессор: Intel Core i3 / AMD Ryzen 3 или лучше
- Оперативная память: 4 GB
- Видеокарта: С поддержкой DirectX 11 / OpenGL 4.5
- DirectX: Версии 11
- Место на диске: 500 MB

## Управление

| Действие | Клавиша |
|----------|---------|
| Движение вверх | Стрелка вверх или W |
| Движение вниз | Стрелка вниз или S |
| Движение влево | Стрелка влево или A |
| Движение вправо | Стрелка вправо или D |
| Пауза | Escape |

## Структура проекта
Assets/
├── Animations/                 # Анимации игрока, врагов и объектов
├── NavMeshCompanion/           # Компаньон для навигации (AI pathfinding)
├── NPS/                        # Неигровые персонажи (вероятно, опечатка: NPC)
├── PlayerInputDetector/        # Система обнаружения ввода игрока
├── Prefabs/                    # Префабы объектов (Player, Enemies, Items)
├── Recovery/                   # Система восстановления (лечение, перезарядка)
├── Resources/                  # Динамически загружаемые ресурсы (квесты)
├── Scenes/                     # Игровые сцены (MainMenu, GameLevel и др.)
├── Scripts/                    # Исходный код игры (ваш Player.cs здесь)
├── Settings/                   # Настройки проекта и конфигурации
├── Sprites/                    # Спрайты и графические ресурсы
├── TextMesh Pro/               # Библиотека для качественного текста в UI
├── Tilemap/                    # Тайловая карта для уровней
├── DefaultVolumeProfile/       # Настройки глобального объема (Post-processing)
└── UniversalRenderPipeline/    # Настройки Universal Render Pipeline (URP)

## Технические детали
GameInput.Instance - должен быть доступен из папки Scripts/PlayerInputDetector
PauseController.IsGamePaused - статическое свойство для проверки состояния паузы
Rigidbody2D - обязательный компонент на объекте игрока
Universal Render Pipeline - используется для рендеринга

##Планы по развитию
Добавление новых локаций, заданий, персонажей и мини-игр, связанных с направлениями факультета.
В дальнейшем планируется масштабирование на другие факультеты и общую инфраструктуру университета. 
Отдельные сюжетные главы будут посвящены конкретным событиям университета, таким как Студенческая весна и хакатоны.
